# Changelog

Full details for each release live in [`release-notes/`](release-notes/). This
file is a one-line index. Keep the Unreleased line current; it becomes the
snapshot's notes on the Check for Updates page, then the next release's line.

- Unreleased — a held ExpressKey shortcut no longer leaves a key down after the pen leaves range; pen clicks and window activation should work on macOS 27.2; a tap that wobbles on contact stays a click; presses and window drags no longer stick on small tablets with large displays; renaming a tablet works again; the Cintiq 24HD Touch pen works again alongside touch; the Cintiq 22HD's three top keys work; the 2017 Cintiq Pro 16 should start its pen and touch reliably; preliminary Cintiq Partner (PTU-600) support; preliminary touch on the Bamboo Pen & Touch 6×8; an Art Pen on Intuos4 and Intuos5-era tablets updates twice as often; Pan View and two-finger scrolling reach Finder's column view more reliably.
- [v0.6.0](release-notes/v0.6.0.md) — the Buttons pane draws your tablet and lights each key; settings turn with the tablet; older Cintiq touch strips and keys.
- [v0.5.2](release-notes/v0.5.2.md) — Cintiq Pro 16 pen and keys; preliminary Cintiq 13HD Touch; contact-only pen buttons; better palm rejection.
- [v0.5.1](release-notes/v0.5.1.md) — tilt and Art Pen rotation in apps again; Art Pen on Intuos4, Intuos5, and Intuos Pro gen 1.
- [v0.5.0](release-notes/v0.5.0.md) — fuller pen input in iWork and Photoshop; a working Intuos Pro eraser; broader PTK and Cintiq support.
- [v0.4.2](release-notes/v0.4.2.md) — multitouch gestures; Bluetooth pen and touch on macOS 27; Intuos Pro M (PTH-651) touch.
- [v0.4.1](release-notes/v0.4.1.md) — pressure threshold setting; more reliable touch controls; device-recognition fixes; lower idle memory use.
- [v0.4.0](release-notes/v0.4.0.md) — pen feel and Pan View; per-unit tablet settings; Xencelabs Pen Display controls.
- [v0.3.0](release-notes/v0.3.0.md) — full Xencelabs Pen Display support, wired and wireless; input reliability under load.
- [v0.2.6](release-notes/v0.2.6.md) — Wacom CTH-690 support; Accessibility permission prompt fix.
- [v0.2.5](release-notes/v0.2.5.md) — expanded wireless accessory support; UI behavior improvements.
- [v0.2.4](release-notes/v0.2.4.md) — first steps toward non-Wacom tablets via a universal HID pen fallback; menu refinements.
- [v0.2.3](release-notes/v0.2.3.md) — bug fixes, touch and interface refinements, broader device recognition.
- [v0.2.2](release-notes/v0.2.2.md) — maintenance release, bug fixes and device registry improvements.
- [v0.2.1](release-notes/v0.2.1.md) — maintenance release with accessibility and interaction improvements.
- [v0.2.0](release-notes/v0.2.0.md) — capacitive touch; a report tool for unrecognized devices; a modifier-key fix during pen drags.
- [v0.1.3](release-notes/v0.1.3.md) — performance improvements; tablet status on all three menu surfaces.
- [v0.1.2](release-notes/v0.1.2.md) — broader hardware support; ring-LED fixes; Scratchpad improvements.
- [v0.1.1](release-notes/v0.1.1.md) — better iWork behavior; sharper device management; a smoother HID hot path.

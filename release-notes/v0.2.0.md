MockTab 0.2.0 adds capacitive touch support, an in-app tool for submitting unrecognised-device reports, and fixes modifier keys during pen drag.

## Capacitive touch

Intuos Pro Gen 2 tablets (PTH-660, PTH-860) now have full touch support over both USB and Bluetooth Classic.

- **Two-finger scroll** — natural or reversed direction, adjustable sensitivity.
- **Tap-to-click** — single-finger tap sends a left click.
- **Touch area editor** — drag the corner handles in the Tablet Area pane to restrict which portion of the surface responds to finger input. Matches the active mapping area by default.
- **Live contact indicators** — the Scratchpad pane shows active touch contacts in real time alongside pen input.
- **Touch pane** — new settings pane consolidates all touch options. The pane appears only for tablets that have a touch surface.

Touch is off by default; enable it in the Touch pane. The physical disable switch on the tablet is respected: MockTab reads its state and shows the current status.

## Unrecognised-device support

The Info pane now includes a **Collect data** button for tablets MockTab does not recognise. It captures a HID descriptor snapshot and guides you through submitting it as a GitHub issue with the right template pre-filled, making it straightforward to request support for a new device.

## Bug fixes

- **Modifier keys during pen drag** — physical ⇧/⌘/⌥/⌃ keys now correctly appear in drag events. Apps like Illustrator and Keynote use modifier state from drag events to activate constraint-snapping and angle locking; these were silently dropped due to a threading issue in the event tap. Express-key modifiers were unaffected.
- **Settings window minimum width** — the minimum width is now derived from the toolbar's actual layout instead of per-locale constants, and correctly accounts for the Touch pane tab being present or absent.
- **Scroll direction label** — renamed from "Natural scrolling" to "Reverse direction" and off by default, to avoid ambiguity with the system trackpad setting. Behaviour is unchanged.

## Compatibility

Same macOS requirement as 0.1.x: macOS 13 (Ventura) or later. Universal binary.

Settings and per-app profiles carry over from all previous releases with no migration required.

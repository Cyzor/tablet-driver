MockTab 0.2.3 is a maintenance release with bug fixes, touch and interface refinements, and broader device recognition.

## Bug fixes

- **Right-click dismissed menus in pressure-aware apps** — synthetic right-click and eraser-button events carried pen-tip pressure, so apps that read pressure to tell a button press from tip contact (QGIS and similar) saw the right-click as a tip-down and closed the context menu immediately. These events now zero tip pressure and set the correct tablet metadata.
- **Renaming a device or profile discarded the new name** — clicking outside the rename field in the Devices and Profiles panes discarded the edit instead of committing it. It now confirms the rename, matching Finder.
- **Mirror-image touch in the Scratchpad** — the live touch visualizer flipped contacts vertically, drawing them as a mirror image of the actual finger layout.
- **Displays pane localization** — several strings in the Displays pane were not localized.

## Touch and interface

- **Steadier touch gestures** — a short onset delay keeps a resting palm or a pen-and-hand landing from nudging the cursor, and two-finger scrolling starts cleanly even when the fingers land a few frames apart. Scrolling also continues smoothly through momentary contact-tracking changes instead of cutting out until every finger lifts.
- **Edit and View menus grey out inapplicable commands** — Cut, Copy, Paste, Select All, and Undo/Redo now enable only when they would do something, and Undo/Redo show the specific action in their titles. Show/Hide Tab Bar is disabled when the active window can't toggle its tab bar and is labeled to match the current state, matching Finder.
- **Scratchpad layout** — the tilt and touch visualizers now sit side by side.
- **Calmer Info readout** — live coordinate and tilt values are quantized so the display no longer flickers between near-identical numbers.

## Responsiveness

The input path is more resistant to system load: the app holds a latency-critical assertion while a tablet is connected (opting out of App Nap and timer coalescing), and internal timing no longer depends on a free main thread. Delivery latency now surfaces in the Info diagnostics.

## Device registry

Added recognition for Wacom MobileStudio Pro models.

## Compatibility

Same macOS requirement as 0.2.2: macOS 13 (Ventura) or later. Universal binary.

Settings and per-app profiles carry over from all previous releases with no migration required.

MockTab 0.1.3 improves performance and brings tablet status to all three menu surfaces.

## Performance

- **Scratchpad rendering** — committed strokes are now cached in an offscreen image. Redraws composite a single blit plus the live stroke instead of re-walking the full stroke history every frame. Drawing remains smooth regardless of how many strokes are on the canvas.
- **Input injection hot path** — eliminated a `CGEventSource.flagsState` kernel round-trip that previously fired on every movement event. High-frequency pen reports (mouseMoved, leftMouseDragged, tabletPointer) now skip the kernel call entirely; only state-change events (mouseDown/Up, click, scroll, flagsChanged) pay it.

## Menu improvements

- **Scratchpad canvas anchoring** — the canvas content stays anchored to the top-left corner when the window is resized. Growing the window reveals blank space at the bottom/right; shrinking clips there first. Previously, strokes would drift.
- **Connected-tablet indicators** — all three menu surfaces now show which tablets are currently connected:
  - *Main app Tablet menu* — filled checkmark icon (unchanged from 0.1.2)
  - *Menu bar icon menu* — `✓` indicator with hanging-indent alignment so all tablet names start at the same column
  - *Dock menu* — standard left-gutter checkmark via `NSMenuItem.state`
- **Menu bar icon** — fixed a regression introduced in 0.1.2 where the menu bar icon would disappear on launch under certain conditions.

## Compatibility

Same macOS requirement as 0.1.2: macOS 13 (Ventura) or later. Universal binary.

Settings and per-app profiles carry over from all previous releases with no migration required.

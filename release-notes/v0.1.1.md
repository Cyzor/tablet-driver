MockTab 0.1.1 is a polish release on top of 0.1.0 — better behavior in iWork apps, sharper device management, and a smoother HID hot path.

## New

- **Devices pane gets removal, rename, and undo.** Right-click a tablet row for "Remove from List…" to wipe all per-device state, double-click a row to rename it (Esc cancels), and undo restores either action.
- **SF Symbols throughout the menus.** Profile and app-override action menus now use system icons for a more native feel.
- **Title-card design asset.** Bundled for use in docs and marketing material.

## Improvements

- **iWork text selection is more reliable.** Refined the synthetic-click payload MockTab posts in Pages, Numbers, and Keynote so body-text drag-selection and floating text-box editing both work consistently. (Header/footer editing remains a known limitation with documented workarounds — see the project notes.)
- **HID hot path is leaner.** The driver no longer allocates a Swift Task per HID report when MockTab itself is backgrounded, and a few `@Published` getters that were running on the 200 Hz path have been removed. Pen latency should be slightly lower under load.
- **PTH-660 / PTH-860 ring LEDs settle correctly on connect.** If the active ring slot changed while the tablet's secondary HID interface hadn't registered yet, the pending value is now applied as soon as that interface arrives.
- **View menu reflects the actual tab-bar state.** "Show Tab Bar" / "Hide Tab Bar" now toggle their label to match the current window.
- **German localization aligned to Wacom usage.** 30 strings updated to use *Tablett* (matching Wacom's German product naming) instead of the prior translation.

## Fixes

- **Factory Reset visibility.** The menu item could be hidden in some states; it's now reliably available.
- **Broken GitHub URLs in the README.** Corrected paths to in-repo notes and references.
- **Stale localization keys.** Removed orphaned `Localizable.xcstrings` entries left behind by earlier UI cleanup.

## Internal

- Extracted modifier-flag math out of `InputInjector` into a `ModifierMath` module with unit tests, and migrated call sites.
- Added regression tests for the IntuosV2 Bluetooth and CintiqV1 HID decoders.
- Replaced an unsafe `Bool` atomicity assumption in `InputInjector.isActive` with `OSAllocatedUnfairLock`.
- Routed all `IOHIDDeviceSetReport` calls through a severity-tagged helper for consistent error handling and logging.
- Replaced a force-unwrap in the HID thread with a guarded `fatalError` that reports the failing condition.
- Reorganized the `Notes/` tree: protocol references stay tracked, ad-hoc scratch work moved under `Notes/Scratch/` (gitignored).
- Wired `Info.plist` version fields to the `MARKETING_VERSION` and `CURRENT_PROJECT_VERSION` build settings so the plist can no longer drift.
- Added `tools/release-and-publish.sh` — the one-button DMG + notarize + draft-release script that built this release.

## Compatibility

- Same hardware support as 0.1.0. macOS 13.0+. Universal binary.
- Settings, calibration data, and per-app profiles carry over from 0.1.0 with no migration required.

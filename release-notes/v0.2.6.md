MockTab 0.2.6 adds support for a new tablet and improves reliability for Xencelabs and Accessibility permissions.

## New hardware

- **Wacom CTH-690 (Intuos Art / Intuos Comic, Medium)** is now supported, including touch and express keys, thanks to a user-submitted device capture.

## Bug fixes

- **Xencelabs tablets could stop responding correctly after a reconnect.** The display quietly re-registers a few seconds after plugging in, which undid the switch into tablet mode; the mode switch now runs again on the connection that stays live.
- **The Accessibility permission prompt now appears when a tablet actually connects**, instead of on every app launch, and the menu bar battery indicator reads more reliably from the active device.

## Internal

- Removed a legacy state mirror in `TabletManager`; battery, transport, USB speed, active tool, and pen/button state now read directly from each device's own tracking, and USB speed is populated correctly at registration.
- Retired the old step-by-step device-capture guide in favor of the free-form discovery recorder, which doesn't misattribute noise between concurrent report streams or stall waiting for signals that never arrive. Also fixes device names incorrectly falling back to "Wacom" for non-Wacom hardware in a few UI spots.
- TabletKit decoder test suite: 314 tests, all passing.

## Compatibility

Same macOS requirement as 0.2.5: macOS 13 (Ventura) or later. Universal binary.

Settings and per-app profiles carry over from all previous releases; no migration is required.

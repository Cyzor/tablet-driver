MockTab 0.1.2 expands hardware support, fixes ring-LED control across all confirmed families, and improves the live Scratchpad.

## New hardware

- **Intuos Pro Gen 3** (PTK-470, PTK-670, PTK-870) — full pen decode including a third pen button, express keys 9–10, and relative scroll wheel. Marked experimental; tilt scale is unverified.
- **DTU small pen displays** (DTU-1631, DTU-2231) — pen decode via the DTU protocol family.
- **DTUS small pen displays** — pen decode via the DTUS protocol family.

## Ring LED fixes

LED control now works correctly for all four confirmed device families:

- **PTH-660 / PTH-860 (USB)** — previous releases sent LED commands to the wrong HID interface, so the ring indicator never updated. Now uses the correct 0x31 / 0x32 report pair on the primary device. Confirmed by live dtrace capture against the official Wacom driver on both models.
- **PTH-660 (Bluetooth)** — corrected the preamble byte and brightness channel encoding in the 0x82 report. The slot byte was already right, which is why the ring appeared to cycle correctly on BT; the fix brings the rest of the frame into spec.
- **Cintiq 24HD / DTK-2400** — ring LED was already functional; confirmed format against live capture and documented.

## Scratchpad improvements

- **Tilt visualizer** — the needle indicator now shows live pen tilt in both axes while hovering.
- **Undo / redo** — ⌘Z and ⌘⇧Z work within the canvas.
- **Eraser** — flipping to the eraser end of the stylus switches to erase mode in the Scratchpad.
- **Touch ring indicator** — the slot indicator in the Buttons pane updates as you cycle ring modes.
- **Appearance polish** — refined layout, spacing, and touch-ring indicator styling.

## Other improvements

- **Cintiq OSD button decode** — the three capacitive touch buttons on the DTK-2400 bezel are now decoded from report 0x0C bytes 3–4 and surfaced as AuxButtons 16–18.
- **Registry accuracy** — two audit passes against Linux input-wacom 4.18 corrected tablet dimensions for ~8 entries and reclassified several misidentified PIDs.

## Compatibility

Same macOS requirement as 0.1.1: macOS 13 (Ventura) or later. Universal binary.

Settings and per-app profiles carry over from 0.1.0 and 0.1.1 with no migration required.

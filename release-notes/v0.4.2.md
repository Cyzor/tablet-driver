MockTab 0.4.2 improves gesture behavior on tablets that support multitouch. Bluetooth pen and touch input are more reliable on macOS 27 Golden Gate.

Improvements to Intuos Pro M touch operation, gesture response, and crop-tool area controls stem from reports and testing by @AntonioGHub. Improved app relaunch follows an approach from @MarsLuay.

## Touch

- Touch responds sooner after finger contact.
- New two-finger **Rotate** gesture. Either gesture can join the other while it is already in progress, so scaling and rotating a canvas become a single continuous motion. Support varies by app.
- Cursor movement now resembles Apple’s trackpad acceleration profile.
- Two-finger scrolling locks to the dominant axis, fixing horizontal scrolling that worked only some of the time in list and column views. Momentum support varies by app.
- A touch gesture interrupted by a nearby pen now ends cleanly instead of vanishing mid-motion.
- The touch-area crop tool now matches each tablet’s actual proportions.
- Fixed an issue in which a hovering pen suppressed finger touch on Intuos Pro, Intuos5, and CTH-690 tablets.
- Fixed an issue in which a two-finger scroll could stick when one finger lifted early.

## Bluetooth

- MockTab now paces pen and touch input, making cursor motion over Bluetooth smoother on macOS 27.
- Fixed touch dropping out during two-finger use.
- Fixed a rare case in which a stuck proximity signal could disable touch until MockTab relaunched.
- Fixed a ghost cursor trail that could appear after a brief system stall.

## Pen and buttons

- Fixed a button that could remain stuck down after switching tools or unplugging the tablet mid-drag.
- Fixed an issue that stopped pen input when a cable joined a live wireless session.
- Pen input now attempts to recover automatically if a tablet stops reporting that the pen has left range.

## Device support

- Added touch support for **Intuos Pro M (PTH-651)**.
- Corrected touch ranges for **CTH-690** and registry entries for several Intuos, Bamboo, and Cintiq models.

## Diagnostics

- Collect Device Data now records more detail about touch behavior and Bluetooth signal strength.

## Compatibility

- Requires macOS 13 Ventura or later; universal binary.
- Settings and profiles from 0.4.1 carry over automatically.
- Known macOS 27 Golden Gate issue: With momentum scrolling enabled, horizontal panning does not work in all column views. Disable momentum scrolling to restore horizontal panning.

MockTab 0.2.1 is a maintenance release with accessibility and interaction improvements

## Accessibility

- **Text Size**: A new View → Text Size submenu (Small / Medium / Large / Extra Large) scales all settings panel text. Useful when the system font size doesn't suit a tool-focused window.
- **VoiceOver**: The active area editor and pressure curve canvas now expose VoiceOver-accessible slider representations. Arrow-key nudging works on macOS 14 and later.
- **Differentiate Without Color**: Status indicator dots in the device status bar and capture guide now switch to filled vs. hollow SF Symbols when the system accessibility setting is on, so the app never relies on color alone to convey status.

## Bug fixes

- **Bluetooth report bounds**: The IntuosV2 Bluetooth decoder now rejects truncated frames before reading past their validated length, matching the upstream input-wacom bounds-check intent.
- **Touch ring mode indicator**: The green checkmark in the Buttons pane now correctly highlights the active mode slot. It previously appeared one slot ahead of the physical LED and ring diagram.
- **Merge All Windows**: The standard Window → Merge All Windows command now works correctly with MockTab's settings window.

## Compatibility

Same macOS requirement as 0.2.0: macOS 13 (Ventura) or later. Universal binary.

Settings and per-app profiles carry over from all previous releases with no migration required.

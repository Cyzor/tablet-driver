MockTab 0.2.4 takes the first steps toward non-Wacom tablets, with menu and menu-bar refinements alongside.

## Experimental non-Wacom support

- **Standard HID pen digitizers now get basic input.** Tablets that follow the standard HID pen-digitizer protocol — including many non-Wacom pens — attach to a universal fallback driver for cursor motion, tip contact, barrel buttons, eraser, and tilt where the device reports them. This is an early, experimental floor: vendor-specific features (extra pressure curves, express keys, rings, dials) are not decoded, and behavior has not yet been validated against real non-Wacom hardware.
- **Xencelabs pen decoding.** Added a dedicated decoder for Xencelabs pen reports, with unit-test coverage.
- **Clearer naming for non-Wacom devices.** Unrecognized non-Wacom tablets are now named from their vendor profile, or from the device's own product string when the profile is ambiguous, instead of a generic placeholder.

## Menus and menu bar

- **Crisper menu-bar icon.** The menu-bar icon now ships as vector PDF artwork for both light and dark appearances, replacing the previous bitmaps.
- **Accurate disconnected-display indicator.** The "display not connected" state uses a clearer SF Symbol.
- **More consistent checkmark items.** Checkmarked menu items render uniformly across the app.
- **Battery level in device menus.** When a Bluetooth tablet is connected, its battery percentage appears next to its name in the menu-bar menu and the dock menu. A charging indicator is shown when the tablet is plugged in.
- **Low-battery alerts.** When a connected tablet's battery drops below 20 % and is not charging, the menu-bar icon switches to a battery-warning symbol and the dock tile shows a `!` badge.

## Bug fixes

- **Factory Reset stayed reachable on newer macOS.** The reset command and its modifier alternates remain reliably available even after window transitions on macOS 27.
- **Device label reflected wrong tablet in multi-tablet sessions.** The device and tool name labels in settings windows followed the globally-active tablet instead of the tablet the window was opened for. Each window now tracks its own device independently.
- **Settings tab could land on the wrong pane.** Tab navigation looked up panes by position rather than by label, so a localized build or any future tab reorder could open the wrong settings pane.

## Internal

- The generic digitizer frame decoder lives in TabletKit with its own unit tests (281 tests total, all passing).
- A tag-triggered GitHub release workflow signs, notarizes, and drafts a release from a pushed `v*` tag, alongside the existing local one-button release script.
- Removed orphaned localization keys.

## Compatibility

Same macOS requirement as 0.2.3: macOS 13 (Ventura) or later. Universal binary.

Settings and per-app profiles carry over from all previous releases with no migration required.

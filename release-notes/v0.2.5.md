MockTab 0.2.5 is a smaller update: a tablet-input regression fix, wireless-dongle button mapping, and a batch of UI polish.

## UI polish

- **Bigger click targets in the Button Mapping pane.** The clickable area for each assignment is wider, and the pane shows clearer text feedback about input status.
- **Arrow-key navigation for app chips.** Use the arrow keys to move between app-override chips, and double-click a chip to rename it.
- **Settings windows remember their size.** A window keeps its size when you close and reopen it for the same device. Switching tabs from the menu bar or a keyboard shortcut no longer resizes the window unexpectedly.
- **Escape now works as a button action**, and Cancel buttons dismiss more consistently across import and capture sheets.
- **Fixed the profile import sheet's appearance.**

## Bug fixes

- **App chip taps sometimes turned into drags.** A quick tap on an app-override chip could start a drag instead of selecting it. Dragging now requires a deliberate press-and-hold, so taps select reliably again.
- **The Button Mapping pane stayed blank for tablets on the ACK-40401 wireless dongle.** Express keys and the touch ring now show up and respond when a tablet connects through the wireless receiver, not just over direct USB.
- **Express keys and the touch-ring center button didn't respond.** A decoder bug read the wrong byte for the key bitmask, so only one express key could ever register a press, and the driver never read the ring's center button at all. Confirmed the fix against real hardware.
- **"Close All Windows" didn't always update correctly.** The menu item now enables and disables correctly and shows its Option-key alternate reliably.

## Internal

- TabletKit decoder test suite: 288 tests, all passing.
- Reduced GPU memory spikes in the settings window.

## Compatibility

Same macOS requirement as 0.2.4: macOS 13 (Ventura) or later. Universal binary.

Settings and per-app profiles carry over from all previous releases with no migration required.

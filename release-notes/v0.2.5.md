MockTab 0.2.5 expands wireless accessory support and improves UI behavior.

## UI

- **Escape is now available as a mappable input**, and Cancel buttons dismiss more consistently across import and capture sheets.
- **Larger click targets for button mapping.** The clickable area for each assignment is wider, and the pane provides clearer text feedback about input status.
- **Easier navigation between app overrides.** Use the arrow keys to move between app-override chips.
- **More consistent sheet appearance.**

## Bug fixes

- **The button mapping pane was incomplete for tablets using an ACK-40401 wireless dongle.** Express keys and the touch ring should now appear and respond when a tablet connects.
- **Express keys and the touch ring did not always respond.** A decoder bug read the wrong byte for the key bitmask, so only one express key could register a press, and the driver did not read the ring’s center button.
- **Selecting an app override could trigger an unintended drag.** Clicking an app-override chip could start dragging it.
- **“Close All Windows” did not always update correctly.** The menu item now enables and disables correctly and reliably shows its Option-key alternate.

## Internal

- Reduced GPU memory spikes in the Settings window.
- TabletKit decoder test suite: 288 tests, all passing.

## Compatibility

Same macOS requirement as 0.2.4: macOS 13 (Ventura) or later. Universal binary.

Settings and per-app profiles carry over from all previous releases; no migration is required.

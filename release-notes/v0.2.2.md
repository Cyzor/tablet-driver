MockTab 0.2.2 is a maintenance release that fixes bugs and improves the device registry.

## Bug fixes

- **Preset and calibration data**: Presets with custom touch ring slots or pen calibration exported those fields as missing.
- **Calibration data lost on preset delete**: Deleting a preset left its calibration data in behind. The app now removes that data with the preset.
- **Duplicate Text Size menu**: View → Text Size submenu duplicated on each window rebuild.
- **Modifier key leak with middle button**: When a barrel button mapped to a modifier ran in mouse-tool mode with the middle button held, releasing the barrel button could release the modifier too early.

## Device registry

Corrected physical dimensions for models where kernel values differed from libwacom:

- **Graphire** (CTB-4×5, GD-0405-R, GD-0608-U, GD-0912-U)
- **Volito** (FT-0405)
- **Cintiq** (DTU-1031)

Added models from libwacom:

- Bamboo One CTF-430
- Bamboo Pad CTH-300
- Bamboo Pad CTH-301

## Compatibility

Requires macOS 13 (Ventura) or later, same as 0.2.1. Universal binary.

Settings and per-app profiles carry over from all previous releases; no migration required.

MockTab 0.2.2 is a maintenance release with bug fixes and device registry corrections.

## Bug fixes

- **Modifier key leak with middle button** — when a barrel button was mapped to a modifier key and the tablet was in mouse-tool mode with the middle button held, releasing the barrel button could prematurely release the synthetic modifier. The quiescence check that decides when to clear held modifiers now correctly accounts for middle-button state.
- **Calibration data lost on preset delete** — deleting a preset left its calibration data behind in storage. The stale entry was harmless but accumulated indefinitely. It is now removed with the rest of the preset.
- **Preset export drops ring and calibration data** — presets with custom touch ring slot configurations or pen calibration data exported those fields as absent. Re-exporting a preset after this update will include the previously missing data; no action is needed for presets that were never exported.
- **Duplicate Text Size menu entry on macOS 26** — the View → Text Size submenu was duplicated on each window rebuild under macOS 26 (Tahoe), leaving multiple identical entries in the menu. Fixed.

## Device registry

Physical dimensions corrected for six models where kernel-derived values were off by 10–25% against libwacom:

- **Graphire** (CTB-4×5, GD-0405-R, GD-0608-U, GD-0912-U): Y axis corrected from 92.8 mm to 102 mm.
- **Volito** (FT-0405): corrected from 102 × 74 mm to 127 × 102 mm.
- **Cintiq DTU-1031**: Y axis corrected from 140 mm to 127 mm.

Three models added from libwacom:

- Bamboo One CTF-430 (0x0069)
- Bamboo Pad CTH-300 (0x0319)
- Bamboo Pad CTH-301 (0x0318)

Dimension corrections affect the default tablet area calculation; the active area setting is preserved across the update.

## Compatibility

Same macOS requirement as 0.2.1: macOS 13 (Ventura) or later. Universal binary.

Settings and per-app profiles carry over from all previous releases with no migration required.

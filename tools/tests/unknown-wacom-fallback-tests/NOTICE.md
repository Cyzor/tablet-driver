# fixtures.txt

The report descriptors in `fixtures.txt` come from the
[linuxwacom/wacom-hid-descriptors](https://github.com/linuxwacom/wacom-hid-descriptors)
database. Each is kept byte for byte, by product ID and bus, with nothing
else from the submission.
